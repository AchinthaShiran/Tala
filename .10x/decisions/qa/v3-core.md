# QA: v3-core

Strategy: pyramid. Unit (domain, arguments, rendering, policy, fencing, index, history, config, trust) -> component with the real OS (subprocess runner: timeout, tree kill, bounded output, no shell) -> pack quality gate (every builtin tool loads lint-clean and renders on Windows/Linux/macOS) -> integration (full LangGraph with scripted chat model, fake runner, in-memory checkpointer) -> CLI (Typer runner, chat loop) -> architecture (import-linter) -> evaluation (golden set; retrieval offline, agent live).
Results (Windows 11, Python 3.12): 253 tests pass, 93% line coverage; ruff, ruff format, mypy --strict (50 files), 2 import contracts, `deskaide packs validate --strict` (95 tools) all clean.
Bugs found by QA during build: (1) adb_install_apk / adb_reboot_bootloader / fastboot_reboot_bootloader were `read_only` due to a suffix heuristic in the migration script (found by live run; fixed with explicit list + two regression tests incl. a verb scanner over every builtin command); (2) single generic word ("today") counted as a strong tool match; (3) Rich markup swallowed `[math]` in displayed commands; (4) legacy Windows code page crashed on glyphs; (5) layering violation evaluation->bootstrap found by the architecture test.
Gaps: Linux/macOS commands are exercised by rendering tests only, not executed (CI matrix will); no property/fuzz tests of argument validation; golden set covers ~35 of 95 tools.
